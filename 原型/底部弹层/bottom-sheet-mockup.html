关联选择弹窗（BottomSheet）

多选 · 搜索 · 类型分组
  • 顶部：把手 + 标题"关联卡片" + 关闭×按钮
  • 搜索框：圆角输入框，实时搜索（输入"复盘"已过滤）
  • 卡片列表：按 待办/灵感/日期 三组排列，每项含勾选框+类型图标+标题+副信息
  • 已选项：橙色背景 + 实心橙勾，未选项灰边框
  • 底部栏："已选 N / 10"计数 + 橙色"完成"按钮
  • 数量限制：每组最多 10 个，达到上限时禁止继续勾选并提示

交互流程

  1. 用户点击 Chips 行下方的 「＋」 或在编辑框输入 「@」 触发弹窗
  2. 弹窗从底部滑入，自动聚焦搜索框，默认列出全部卡片
  3. 用户输入关键词，列表实时过滤（跨三类型）
  4. 用户点击卡片项切换选中状态（橙色背景 + 勾选）
  5. 底部"已选 N/10"实时更新，达上限时禁止继续选
  6. 点击"完成"按钮 → 保存关联到当前分组 → 关闭弹窗 → Chips 行下方显示已选 Chip
  7. 点击 × / 遮罩 / 系统返回键 → 取消选择 → 关闭弹窗
