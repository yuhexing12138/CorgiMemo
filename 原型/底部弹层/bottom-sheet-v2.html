关联选择弹窗 v2（含分组折叠）

多选 · 搜索 · 类型分组 · 可折叠
  • 分组标题可点击：切换折叠/展开，箭头 ▼ 旋转动画
  • 折叠时显示：类型图标 + 类型名 + 总数徽章 + 已选徽章
  • 展开时显示：上述标题 + 卡片列表
  • 顶部：把手 + 标题"关联卡片" + ×关闭
  • 搜索框：实时过滤（跨三类型），搜索时自动展开有匹配项的分组
  • 卡片项：勾选框 + 类型图标 + 标题 + 副信息
  • 已选项：橙色背景 + 实心橙勾
  • 底部栏："已选 N / 10" + 橙色"完成"按钮

分组折叠交互

  1. 默认状态：所有分组展开（首次打开时）
  2. 点击分组标题 → 该分组折叠（箭头旋转 -90°）
  3. 再次点击 → 重新展开
  4. 用户输入搜索词时，有匹配项的分组自动展开
  5. 分组记忆用户上次选择（关闭弹窗后再打开仍保留折叠状态）
