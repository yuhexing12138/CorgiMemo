### 真根因（修正 v10.4 的归因）
**`TextSelection.near($pos)` 从未真正把光标移出视频块**：它继承 Selection.near，findFrom 的 textOnly 默认 false，对相邻 atom node（video，content=none 且 selectable）直接返回 NodeSelection 而不是跳过——
- v10.4：near(resolve(5)) → NodeSelection(video@6)：层级从 blockContainer 变到 video 层 → class 从 .bn-block-outer 挂到 .bn-block-content → "collapse 后反而有框"；BN selChange store=true 也是这次层级迁移的 selectionUpdate（**不是合成点击重选**——合成点击只是让第二次长按的 dispatch 变同位）。
- v10.5：下沉后选区本就是 NodeSelection(video@6) → near(resolve(6)) → findFrom 向后第一个命中 video 自己 → **同位 NodeSelection → prev.eq(new)=true → PM 无事发生** → class 残留。PM 的 class 清理入口 syncNodeSelection/clearNodeSelection 根本不触发。
