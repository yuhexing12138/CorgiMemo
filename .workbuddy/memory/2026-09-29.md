## 视频全屏按钮灰色根因 + 原生全屏实现（15:2x）

- **用户问题**：灵感编辑页插入视频后，右下角全屏按钮灰色不可点。

- **实现**（仅 BlockNoteEditorWebView.kt，probe 页不动）：WebChromeClient 匿名对象内新增 `fullscreenDialog: Dialog?` 字段 + `onShowCustomView`（全屏黑底 Dialog `Theme_Black_NoTitleBar_Fullscreen` 承载 Chromium custom view，MATCH_PARENT letterbox）+ `onHideCustomView`；退出三路收敛：返回键→Dialog cancel→callback.onCustomViewHidden()；Chromium 侧退出（控件"退出全屏"/JS exitFullscreen）→dismiss（不回调 callback）；已在全屏中再请求→直接 onCustomViewHidden 防叠加。Dialog 必须用 Activity：新增文件级 `private tailrec fun Context.findHostActivity()`（对 createEditorWebView 的 context 逐层解包，失败按"无能力"收场不崩溃）。
- **本版边界**：不强制横屏（竖屏横视频上下黑边）、不做 Activity 重建恢复（WindowLeaked 告警收尾）；全屏自动横屏留待迭代。onHideCustomView 路径**不调** callback.onCustomViewHidden（callback 只在宿主主动退出时通知用）。
