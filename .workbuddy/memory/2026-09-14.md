## 上游核查：compose-rich-editor 原作者是否新增「跨块连续选中」
- 本机 git 走代理访问 github.com 返回 502（剥离代理变量后仍受 shell 环境破坏影响：cat/head/sed/cd 缺失）。改用 WebFetch 直连原作者仓库（走独立通道，正常）。
- 核查对象：上游 `MohamedRejeb/compose-rich-editor` 的 `richeditor-compose/.../model/RichTextState.kt` 与仓库页。
- 结论：**原作者库从未、且架构上无法提供「跨多个独立编辑器实例（Block）连续选中文本」能力**。
  - `RichTextState.selection` 类型为单实例 `TextRange`，setter 强校验 `value.max <= textFieldValue.text.length`，范围无法指向其他实例文本；各 `RichTextState` 经 `rememberRichTextState()` 完全隔离，无共享引用、无 cross-block/multi-editor 选区概念；无 `selectAll`/`onSelectionChange` 等公共跨块 API。
  - 最新上游动态（2026-09-05）为 bump coil 等依赖；近期特性为 undo/redo history、`compose-1.12`、json 模块、文档，均无跨块选择。
- 区分：库**支持单编辑器内跨多段落选中**（一个 AnnotatedString），但**不支持跨多个独立编辑器块**——后者即 App 层此前自实现的 feature，库无等价原生实现可"恢复"。删除该 feature 逻辑自洽、无上游替代。
