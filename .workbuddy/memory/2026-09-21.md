# 2026-09-21 工作日志

## 灵感编辑页：T / Aa 面板展开期间抑制软键盘（已实施，待真机验证）

**需求**：底部工具栏「T 字体面板」（FontPickerPanel）与「Aa 字号颜色面板」（FontSizeColorPanel）
展开时，用户在**正文中聚焦光标 / 多选**不得唤起软键盘——键盘会把"占键盘位"的面板顶走，
并压缩 WebView 视口（与 v1.11.9 的"视口坍缩到一行高"同源正反馈）。

**落地位置**
- `ui/screens/probe/BlockNoteEditorWebView.kt`
  - 新增 `private class ImeSuppressibleWebView : WebView` + `IME_SUPPRESS_SCRIPT` 常量。
  - `BlockNoteEditorWebView` Composable 新增 `suppressIme: Boolean = false`（默认 false，
    探针页 BlockNoteEditorScreen 与阅读卡不受影响）；在 `AndroidView.update` 里同步状态。
- `ui/screens/inspiration/InspirationEditScreen.kt`
  - 新增派生值 `isFormatPanelOpen = isFontPanelExpanded || isSizeColorPanelExpanded`。
  - 正文 WebView：`suppressIme = isFormatPanelOpen`。
  - 顶部标题 `RichTextEditor`：面板展开时用 `PointerEventPass.Initial` 消费指针事件
    （点击不聚焦 ⇒ 自然不弹键盘）；**刻意不用 `enabled = false`**（会切成禁用色并清焦点）。
- `components/InspirationEditBottomBar.kt`：KDoc「交互规则」同步。

**抑制手段共 4 层（全部保留，互兜）**
1. `isImeSuppressed` setter 变化即 `hideSoftInputFromWindow`（收掉可能已弹出的键盘）；
2. `onCreateInputConnection` 返回 null；
3. `onCheckIsTextEditor` 返回 false；
4. 页面注入 `inputmode="none"`（Chromium 官方键盘抑制语义）+ MutationObserver 持续补标，
   解除时按 `data-ime-prev` 精确还原。

**关键约定**
- 抑制期间**保留光标与选区**（点击定位 / 长按选词 / 拖手柄多选全部保留）；
- 收起面板只恢复"可唤起"能力，**不主动弹回**键盘（用户再点一次正文/标题即恢复）；
- JS 注入必须覆盖三个时机（缺一不可）：状态变化 / `onPageFinished` / 桥 `ready`（DOM 才挂载）。

**回退点**：若个别 ROM 上选择手柄 / 浮动工具条异常，注释掉两个 override 即退到
「JS inputmode + 主动隐藏」两道，焦点与选区走原生默认路径。
