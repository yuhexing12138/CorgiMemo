# 2026-08-26 工作日志

## preview_stack.html 增加 yOffset 参数
- 文件：`图片库/preview_stack.html`（SwipeableImageStack 原型，严格对齐 Compose 实现）
- 为 `SwipeableImageStack` 组件新增 `yOffset` prop，默认 **8**（与原硬编码值一致）
- `stackOffset = ei * 8` 改为 `stackOffset = ei * yOffset`（ei 为饱和夹取的有效层索引）
- 控制面板「堆叠」区新增 yOffset 滑块（范围 0–80px，默认 8px）
- 容器高度改为 `cardHeight + max(0.15×cardHeight, (M-1)×yOffset)`，防止纵向展开溢出
