## 灵感编辑页三个 bug 修复（16:00 起）
- **Bug ① 图片相互重叠（v1 修复：toAddRichSpanStyle 污染）**：根因是 `RichTextState.toAddRichSpanStyle` 全局态——连续插入图片时上一张图的 Image style 污染下一段的前导 `\n`，两张图落到同一段 lineHeight 取 max → 绘制位置相同。修复 `insertBlockImage`：先 reset toAdd 为 Default → addText("\n") 段尾分隔 → addRichSpan(Image) → addText("\n")。同时给 Image 初始宽高 200.sp × 200.sp（替代原来的 0.sp），避免插入瞬间段高退化成"一行文字"导致图片压在后续内容上。
- **Bug ① 第二轮根因（v2 修复：raw text 字符错位）**：`addText("\n")` 让 Image span 的 text 字段 = "\n"，但 `Image.appendCustomContent` 不 append(richSpan.text)，渲染时只输出 inline-content placeholder（U+FFFD）。raw text 字符 "\n" 在 annotatedString 中被替换为 placeholder，**layout 不会把它当换行处理**——连续两张图的 lineTop 重叠。markdown parser 解析 `![](path)` 时把 image span 的 text 设为 "\uFFFD"（与 placeholder 字符值一致），offset 1-to-1 映射正确。**最终修复**：`insertBlockImage` 改用 `richTextState.insertMarkdownAfterSelection("\n\n![](path)\n\n")` 走 markdown 解析路径，前后各 2 个 `\n` 形成独立段，image span 独占段。
- **Bug ② 编辑态点图片预览不是「图片附件」全屏模式**：原实现是 `Dialog + Box + InlineImagePreview` 单图预览，缺失缩放/左右切换/删除/下载。改为复用现有 `InspirationImageGallery`（沉浸式 + HorizontalPager + ZoomableImage + 下载 + 删除）。图片路径列表从 `richTextState.toMarkdown()` 用 `!\[[^\]]*\]\(([^)]+)\)` 正则扫描（即 `saveInlineMediaBlocks` 的同款 Markdown 图片语法）；删除按钮走 `setMarkdown(去掉对应行)` 路径重建 RichTextState。
- **Bug ③ 插入语音后正文无 🎤 标识**：根因 `addRichSpan(RichSpanStyle.Token(...))` 只对"已有选区"生效，collapsed selection（光标闪烁）下什么也不做 → 录音结束后正文里没有任何标记。改为用库的公共 `insertMarkdownAfterSelection("[🎤mm:ss](trigger:voice:path|duration)")`，走 setMarkdown 路径，库自动从伪链接语法解析为 RichSpan(text=label, richSpanStyle=Token)，label 作为 raw text 进入正文。
- 配套：注册 `voice` trigger（用于 Token 渲染颜色，char 用 `/`，因为 voice 不通过输入字符触发，token 只在录音成后整体插入）；删除 `v2026-08-01 Phase 4 回退` 的过时注释；清理 `import androidx.compose.ui.window.Dialog`。
- **关键经验**：库内 inline content 在 raw text 中必须占 1 个 U+FFFD 占位符字符（与 rendered placeholder 字符值一致）才能让 offset 1-to-1 映射、layout 行为正确。用 `addText("\n")` 创建 image span 会让 raw text 字符 = "\n" 但 rendered = U+FFFD，layout 不会按换行处理。**所有 image 插入都应走 markdown parser 路径**，不要直接 `addText + addRichSpan(Image)`。
