# 堆叠图展开/收起功能设计文档

> 创建日期：2026-08-25
> 组件：`SwipeableImageStack.kt`
> 方案：A（内部状态切换，卡片实例不重建）

---

## 1. 需求概述

灵感首页多图堆叠场景中，用户点击"展开"按钮后，堆叠的扇形图片向右展开为横向排列，可左右滑动查看全部图片。展开状态下第一张图片左侧出现"收起"按钮，点击后图片收起回堆叠状态。

### 需求清单

| 编号 | 需求 | 确认结果 |
|------|------|---------|
| R1 | 展开动画方式 | 扇形展开→横排（旋转归0、Y偏移归0、等距排列） |
| R2 | 展开范围 | 全部图片横向排列 |
| R3 | 展开方向 | 向右展开，第一张保持在原位 |
| R4 | 拖拽交互 | 展开状态下禁用拖拽翻牌，仅横向滑动 |
| R5 | 收起按钮 | 位于第一张图片左侧，与展开按钮视觉一致 |
| R6 | 角标 | 展开状态下不显示"1/10"角标 |
| R7 | 展开按钮显示条件 | ≥2 张即显示（现有逻辑不变） |

## 2. 架构设计

### 2.1 核心思路

在 `SwipeableImageStack` 内部新增 `isExpanded: Boolean` 状态，通过同一个状态驱动布局模式切换和动画过渡。**卡片 Composable 实例不重建**，动画通过现有 Animatable + LaunchedEffect 自然过渡。

### 2.2 两种布局模式

| 模式 | isExpanded | 布局结构 | 卡片目标值 | 容器宽度 | 滚动 |
|------|-----------|---------|-----------|---------|------|
| 堆叠 | false | 现有 Box + 扇形 | rotation=-45°~0°, y=-24~0, scale=0.85~1 | bboxWidth | 不可滚动 |
| 展开 | true | 同一 Box + horizontalScroll | rotation=0°, y=0, scale=1, x=stackIndex×(cardW+gap) | cardCount×(cardW+gap)-gap + collapseBtnWidth | 可左右滑动 |

### 2.3 关键设计决策

- **不切换 Box→Row**：保持同一个 Box 容器，仅改变容器宽度 + 卡片目标值 + 加 `horizontalScroll`。卡片 Composable 实例不重建，动画通过现有 `Animatable.animateTo()` 自然过渡
- **不使用 LazyRow**：灵感图片数量通常 5-20 张，`Row + horizontalScroll` 足够，避免 LazyRow 的 recycle 频率与 Animatable 冲突
- **内部状态管理**：`isExpanded` 由组件内部 `remember` 管理，点击展开/收起按钮直接切换，同时暴露 `onExpandStateChange` 回调供调用方响应
- **展开后顺序 = 当前堆叠顺序**：展开时按 `stackIndex`（顶卡=0，底层=cardCount-1）作为 X 偏移依据，**不**按 `originalIndex` 排序。这样顶卡天然落在最左侧（满足 R3"第一张保持在原位"），无需对卡片重排，动画过渡更平滑

### 2.4 术语对齐

| 术语 | 含义 |
|------|------|
| 顶卡 | `stackIndex = 0` 的卡片，当前堆叠中可见的最顶层图片 |
| 第一张图片 | 展开态下位于最左侧的图片 = 顶卡（即 `stackIndex = 0`） |
| `stackIndex` | 当前堆叠顺序索引，顶卡=0，越往下 index 越大 |
| `originalIndex` | 用户翻牌前的原始顺序索引，本次展开/收起**不使用**此变量 |

## 3. API 变更

### 3.1 新增参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `cardGap` | `Dp` | `8.dp` | 展开时卡片间距 |
| `onExpandStateChange` | `((Boolean) -> Unit)?` | `null` | 展开/收起状态变化回调 |

### 3.2 已有参数（不变）

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `showExpandButton` | `Boolean` | `false` | 堆叠时是否显示展开按钮 |
| `countBadge` | `Boolean` | `false` | 堆叠时是否显示角标 |

### 3.3 内部状态

```kotlin
var isExpanded by remember { mutableStateOf(false) }
val expandedScrollState = rememberScrollState()
```

### 3.4 UI 元素显隐规则

| 元素 | 堆叠模式 (isExpanded=false) | 展开模式 (isExpanded=true) |
|------|---------------------------|--------------------------|
| 扇形卡片 | 显示，fan 逻辑目标值 | 显示，展开态目标值 |
| countBadge 角标 | 显示（if countBadge && cardCount > visibleDepth） | 隐藏 |
| 展开按钮 | 显示（if showExpandButton && cardCount >= 2） | 隐藏 |
| 收起按钮 | 隐藏 | 显示，位于第一张图片左侧 |
| 拖拽翻牌 | 启用 | 禁用 |
| horizontalScroll | 不挂载 | 挂载 |

### 3.5 收起按钮

- **样式**：与展开按钮完全一致（灰底半透明胶囊 `#F2F3F5@55%` + 11sp Medium + ChevronRight 图标）
- **文本**：显示"收起"
- **定位**：位于第一张图片（顶卡，stackIndex=0）左边缘左侧，垂直居中于第一张图片
- **实现**：用 `TopStart + padding(start, top)` + `onSizeChanged` 读取实际高度后 `graphicsLayer.translationY` 回移一半（与展开按钮相同的精确居中方案）
- **宽度估算**：`collapseBtnWidth ≈ 文本宽度 + padding + icon`，与展开按钮一致；实际宽度通过 `onSizeChanged` 读取，用于 4.4 容器宽度计算（`boxWidth = cardCount×(cardW+cardGap)-cardGap + collapseBtnWidth + 间距`，间距=展开按钮与顶卡的间距一致，约 8dp）

## 4. 动画过渡

### 4.1 动画驱动

复用现有 5 个 Animatable（positionX, positionY, scaleAnim, rotationAnim, zIndexAnim），无需新增动画状态。

### 4.2 LaunchedEffect 触发条件

```kotlin
// 现有：LaunchedEffect(stackIndex, order.size)
// 改为：LaunchedEffect(stackIndex, order.size, isExpanded)
//   → isExpanded 变化时，所有卡片重新 animateTo 新目标
```

### 4.3 目标值计算

```kotlin
/**
 * 计算卡片在堆叠/展开两种状态下的动画目标值
 *
 * 堆叠状态（扇形）：
 *   - rotation: 0° / -15° / -30° / -45°（线性均分）
 *   - Y 偏移: 0 / -8 / -16 / -24（每层上移 8px）
 *   - scale: 1.0 / 0.95 / 0.90 / 0.85（每层缩小 5%）
 *   - zIndex: 4 / 3 / 2 / 1（顶卡最高）
 *
 * 展开状态（横向排列）：
 *   - rotation: 0°（归零）
 *   - Y 偏移: 0（归零）
 *   - scale: 1（归一）
 *   - X 偏移: stackIndex × (cardW + cardGap)（顶卡=0 在最左侧，等距向右排列）
 *   - zIndex: 1（统一层级）
 */
fun getCardTarget(stackIndex: Int, isExpanded: Boolean): Target
```

### 4.4 容器尺寸计算

| 模式 | boxWidth | boxHeight |
|------|---------|---------|
| 堆叠 | max(cardW+xOffset, bboxWidth, badgeRequiredRight) | max(cardH+stackVP, bboxHeight) |
| 展开 | cardCount × (cardW + cardGap) - cardGap + collapseBtnWidth | cardH |

### 4.5 horizontalScroll 挂载

```kotlin
Box(
    modifier = modifier
        .size(boxWidth.dp, boxHeight.dp)
        .then(if (isExpanded) Modifier.horizontalScroll(expandedScrollState) else Modifier)
)
```

### 4.6 拖拽禁用

```kotlin
// pointerInput 仅在 !isExpanded && isTopCard 时挂载
if (!isExpanded && isTopCard) {
    Modifier.pointerInput(slot.stableId, swipeDirection) { ... }
} else {
    Modifier
}
```

## 5. 数据流

```
用户点击"展开" → isExpanded = true
  → LaunchedEffect(stackIndex, order.size, isExpanded) 触发
  → 5 个 Animatable animateTo(展开态目标值)
  → 卡片视觉从扇形过渡到横排
  → countBadge/expandButton 淡出
  → collapseButton 淡入
  → horizontalScroll 挂载
  → onExpandStateChange?.invoke(true)

用户点击"收起" → isExpanded = false
  → 反向过渡
  → scrollState 归零
  → onExpandStateChange?.invoke(false)
```

## 9. V1.1 Bug 修复（2026-08-25，场景 A）

> **Bug 现象**：① 展开后图片全部重叠（没有横向等距排列）；② 展开后想收起找不到按钮（收起按钮随滚动滚走，或因外层 Box size 跳变被裁掉不可见）
>
> **用户硬约束**：严格按 `图片库/expand-collapse-stack.html` 原型设计，堆叠态下**堆叠图位置 / 角标位置 / 展开按钮位置绝对不能变**
>
> **用户关键决策（2026-08-25 最终确认）**：
> - 锚点：**堆叠态 = Center（完全复用 V1.0 不改动），展开态 = TopStart（与原型 HTML L358-361 `index*(W+G)` 严格一致）**，两套锚点并存，互不干扰
> - 滚动范围：仅限内部卡片区，按钮独立于滚动区永远不滚
> - 收起按钮：独立于滚动区（与 ScrollArea 同级 Row 的首元素），不随卡片滚动；**取消飞出（不使用 translationX 负偏移）**，整 Row 位于 Stage 内容区内部，避免与时间线重叠
> - ScrollArea 宽度：**独立于 stageBoxWidth（堆叠宽度）**，设 maxWidth（如 480dp）保证卡片有充足横向空间
> - 渲染循环：**单循环合并（堆叠/展开各目标值分支）**，消除两套独立 forEachIndexed，卡片实例不重建，过渡最流畅

### 9.1 Bug 根因分析

| Bug | 根因 | 影响 |
|-----|------|------|
| **① 展开后图片重叠** | 堆叠态 `contentAlignment = Center`，展开态改为 `TopStart`；同时外层 Box size 与内部容器 size 都跳变，导致**卡片基准点跳变**，堆叠态残留的 dragOffset 在展开态仍被顶卡叠加（`finalX = positionX + dragOffsetX`）→ 顶卡与下层卡错位，视觉重叠 | 展开后卡片无过渡直接堆叠 |
| **② 展开按钮/收起按钮不可见** | 原实现把 `horizontalScroll` 直接挂在**外层 Box** 上，外层 Box 同时包含角标/展开按钮（绝对定位元素）。展开后外层 Box 变宽并可水平滚动，角标和展开按钮 `!isExpanded` 时被 if 块隐藏本属正常，但**收起按钮**也挂在可滚动的外层 Box 内 → 用户一滑就滚走，无法收起 | 展开后无法返回堆叠态 |

### 9.2 修复方案 A：单循环 + 三层结构（用户 2026-08-25 通过）

重构 SwipeableImageStack 根节点为三层严格对应原型 DOM，**消除两套独立渲染循环（合并为一套）**：

```
┌─────────────────────────────────────────────────────────────────────────┐
│  Stage（外层固定舞台 Box）                                               │
│   - size 永远 = 堆叠态 bbox 需求（含展开按钮空间 + 角标空间）            │
│   - 永远不挂 horizontalScroll；Modifier.clip(false) 防溢出裁剪          │
│   - (0,0) = 堆叠区顶卡左上角（与标题/正文/标签左对齐基准点一致）          │
│   │                                                                     │
│   ├─ 堆叠态分支（isExpanded = false）：完全保留 V1.0                    │
│   │   ┌──────────────┐   ← Badge(1/N)       Stage 独立子元素，不滚动    │
│   │   │ CardContainer│   ← ExpandBtn(展开N) Stage 独立子元素，不滚动    │
│   │   │ [单渲染循环]  │                                                  │
│   │   └──────────────┘                                                  │
│   │                                                                     │
│   └─ 展开态分支（isExpanded = true）：对应原型 stage-content            │
│       ┌───────────────────────────────────────────────────────────┐     │
│       │ Row (verticalAlignment = CenterVertically)                │     │
│       │  ├─ CollapseBtn（收起）← Row 首元素，**不飞出不 translationX** │     │
│       │  ├─ Spacer(width = 8.dp)                                   │     │
│       │  └─ ScrollArea (Box, maxWidth=480dp) ← 唯一挂 horizontalScroll │
│       │      └─ CardContainer (TopStart 对齐)                       │     │
│       │          └─ [单渲染循环] 同一批卡片实例，目标值切换为横排       │     │
│       └───────────────────────────────────────────────────────────┘     │
└─────────────────────────────────────────────────────────────────────────┘
```

**关键架构变更：**
1. **合并渲染循环**：消除原 V1.0 展开态（~400 行）和堆叠态（~240 行）两套独立 `forEachIndexed`，合并为**一套**，通过 `isExpanded` 在目标值层面切换
2. **卡片实例永不重建**：`key(slot.stableId)` + 同一 Composable 作用域 → Animatable 状态连续 → 过渡动画最流畅
3. **ScrollArea 宽度独立**：maxWidth=480dp 不绑定 stageBoxWidth（~200dp）→ 5 张图需 632dp 空间充足
4. **CollapseBtn 不飞出**：Row 首元素正常位置，整个 Row 在 Stage 内部，不超出左边界 → 不与 x=60dp 的时间线竖线重叠

### 9.4 尺寸计算

#### 9.4.1 Stage 外层 size（堆叠态 = 永远不变，保证位置绝对不变）

完全复用原堆叠态 `boxWidth` / `boxHeight` 计算（SwipeableImageStack.kt L449-L466），**不随 isExpanded 变化**：

```kotlin
// stageBoxWidth 永远 = 堆叠态需求（Stage 的 size 永不变化 → 位置绝对不变）
val stageBoxWidth = maxOf(
    cardWVal + xOffset.value,           // 扇形水平摊开
    bboxWidth,                          // 旋转+scale 包围盒
    badgeRequiredRight,                 // 1/N 角标右端
    expandRequiredRight,                // "展开 N"按钮右端
    cardBoxStartX + bboxWidth           // 顶卡左上角 + 包围盒
)
val stageBoxHeight = maxOf(
    cardHVal + stackVPVal,              // 扇形垂直摊开
    bboxHeight                          // 旋转+scale 包围盒高
)
```

Stage Modifier 关键追加：
```kotlin
Modifier
    .clip(false)   // 允许左负偏移（收起按钮）/ 右溢出不被裁剪
    .size(stageBoxWidth.dp, stageBoxHeight.dp)
    // ！！ 永远不挂 horizontalScroll ！！
```

#### 9.4.2 ScrollArea（展开态才出现）

- 挂在 Stage 内展开态的 Row 第二子元素（与 CollapseBtn 同级）
- `Modifier.height(cardHeight.dp).fillMaxWidth()` 或 = Stage 可用宽度 − CollapseBtn 宽 − gap
- 唯一挂 `horizontalScroll(expandedScrollState)` 的层
- ScrollArea 内部 `contentAlignment = TopStart`（CardContainer 从 ScrollArea 起点开始排）

#### 9.4.3 CardContainer（两种状态，各用不同 contentAlignment + 单渲染循环共用）

```kotlin
// ========== 堆叠态 CardContainer ==========（与 V1.0 完全一致，0 改动）
val stackCardBoxW = bboxWidth
val stackCardBoxH = bboxHeight
// contentAlignment = Center（与 V1.0 一致）
// graphicsLayer.translationX/Y = cardBoxStartX / cardBoxStartY（把 Center 对齐后的顶卡左上移到 Stage(0,0)）

// ========== 展开态 CardContainer ==========（严格对应原型 L193 L456）
val cardRowWidth = cardCount * (cardWidth.value + cardGap.value) - cardGap.value  // 原型 L456
val expandedCardBoxW = cardRowWidth
val expandedCardBoxH = cardHVal
// contentAlignment = TopStart（关键！与原型一致，卡片从左上角开始排）
// graphicsLayer.translationX = 0，translationY = 0（不需要再偏移，TopStart 天然对齐 ScrollArea 左上）
```

**两种状态下顶卡（stackIndex=0）左上角精确对齐保证（位置 100% 不变的核心）：**

| 状态 | CardContainer 基准点 | topCard positionX | topCard positionY | graphicsLayer translationX/Y | **顶卡左上角绝对坐标** |
|------|-------------------|-------------------|-------------------|------------------------------|----------------------|
| 堆叠态 | CardContainer(Center) + bboxWidth/2×bboxHeight/2 | `-bboxLeft + cardW/2 - cardBoxStartX`（V1.0 现有） | V1.0 现有 | `translationX=cardBoxStartX`<br>`translationY=cardBoxStartY` | **(0, 0) Stage 左上角** |
| 展开态 | ScrollArea(TopStart) + (0,0) | `stackIndex=0 → 0 × (W+G) = 0` | `0`（目标值归零） | `translationX=0`<br>`translationY=0` | **(0, 0) ScrollArea 左上角** = Row 第二子元素起点 → 见下方 9.4.4 精调 |

#### 9.4.4 展开态 Row 的起始位置（保证顶卡左上角与堆叠态精确吻合）

为保证展开后顶卡左上角**精确落在与堆叠态完全相同的像素坐标**（用户硬约束「位置绝对不变」），展开态 Row 不能从 Stage(0,0) 直接开始，需要用 `padding` 精确定位：

```
展开态 Row 起点 padding(start = topCardXOffset, top = topCardYOffset)
  其中：
    topCardXOffset = cardBoxStartX - bboxLeft （堆叠态顶卡左上角相对 Stage 的 X 偏移，V1.0 公式）
    topCardYOffset = cardBoxStartY + ...       （堆叠态顶卡左上角相对 Stage 的 Y 偏移，V1.0 公式）
```

**这样 CollapseBtn 在 Row 首元素，位于顶卡左侧但不飞出 Stage，不与时间线重叠；而顶卡左上角 = 堆叠态顶卡左上角，位置 100% 不变 ✓**

### 9.5 单渲染循环 + 目标值双分支（TopStart 展开公式，用户 2026-08-25 通过）

**核心原则：一套 `order.forEachIndexed`，不根据 isExpanded 复制两套循环。堆叠态（扇形）完全保留 V1.0 目标值，不做任何改动 → 堆叠视觉与位置 100% 不变。**

**展开态（横排）targetX 严格对应原型 HTML L358-361：`x: index * (CARD_W + CARD_GAP)`**

```kotlin
val M = minOf(visibleDepth, cardCount).coerceIn(1, 4)
val ei = minOf(stackIndex, M - 1)
val denom = max(M - 1, 1)
val effectiveTiltAngle = -(M - 1) * 15f

// ============== 目标值（单分支 if isExpanded，单循环共用）==============
val targetX = if (isExpanded) {
    // 展开态（TopStart 锚点，严格对应原型 L358-361）：
    //   stackIndex=0（顶卡）→ x=0 × (W+G) = 0 → 左上角对齐 CardContainer(0,0) = ScrollArea(0,0)
    //   stackIndex=1（下一张）→ x=1 × (W+G) = 128 → 向右等距排列
    //   ...
    // 公式：stackIndex * (cardWidth + cardGap)
    stackIndex.toFloat() * (cardWidth.value + cardGap.value)
} else {
    // 堆叠态扇形：完全复用 V1.0 公式，0 改动
    if (M > 1) ei.toFloat() / denom * xOffset.value else 0f
}
val targetY = if (isExpanded) {
    // 展开态 Y 归零（顶卡与下层卡同一水平线）
    0f
} else {
    // 堆叠态扇形：完全复用 V1.0 公式，0 改动
    -(ei * 8f)
}
val targetScale = if (isExpanded) {
    1f // 展开态 scale 归一
} else {
    // 堆叠态扇形：完全复用 V1.0 公式，0 改动
    1f - ei * 0.05f
}
val targetRotation = if (isExpanded) {
    0f // 展开态 rotation 归零
} else {
    // 堆叠态扇形：完全复用 V1.0 公式，0 改动
    if (M > 1) tiltAngleStart + ei.toFloat()/denom * (effectiveTiltAngle - tiltAngleStart) else tiltAngleStart
}
val targetZIndex = if (isExpanded) {
    // 展开态统一平面层，避免遮挡点击
    1f
} else {
    // 堆叠态扇形：完全复用 V1.0 公式，0 改动（顶卡最高）
    (order.size - stackIndex).toFloat()
}

// ============== LaunchedEffect 触发（增加 isExpanded 作为 key）==============
// 堆叠→展开 / 展开→堆叠 切换时，同一批卡片实例的 5 个 Animatable 平滑 animateTo 新目标
LaunchedEffect(stackIndex, order.size, isExpanded) {
    positionX.animateTo(targetX, TRANSITION_SPRING)
    positionY.animateTo(targetY, TRANSITION_SPRING)
    scaleAnim.animateTo(targetScale, TRANSITION_SPRING)
    rotationAnim.animateTo(targetRotation, TRANSITION_SPRING)
    // zIndex 走独立 ZINDEX_TWEEN
}
```

### 9.6 拖拽互斥与 dragOffset 锁（消除展开态叠加偏移造成的重叠）

```kotlin
// ① pointerInput（拖拽手势）：仅堆叠态 + 顶卡才挂载
if (isTopCard && !isExpanded) {
    Modifier.pointerInput(Unit) { /* 现有拖拽代码 */ }
}

// ② finalX/Y：仅堆叠态 + 顶卡才叠加 dragOffset
//    → 展开态下 dragOffset 残留值不影响最终位置，消除图片重叠根因 2
val finalX = if (!isExpanded && isTopCard) positionX.value + dragOffsetX.value else positionX.value
val finalY = if (!isExpanded && isTopCard) positionY.value + dragOffsetY.value else positionY.value

// ③ finalScale：展开态按下不放大（不支持拖拽）
val finalScale = if (!isExpanded && isTopCard && isPressed.value) scaleAnim.value + 0.05f else scaleAnim.value

// ④ finalRotation：展开态按下不归零（不支持拖拽）
val finalRotation = when {
    !isExpanded && isTopCard && isPressed.value          -> 0f
    !isExpanded && isTopCard && shouldReturnToCenter.value -> 0f
    else                                                   -> rotationAnim.value
}

// ⑤ zIndex 提升：展开态按下不跳 1000（不支持拖拽）
LaunchedEffect(stackIndex, order.size, isExpanded, isPressed.value, isTopCard) {
    zIndexAnim.animateTo(
        target = if (!isExpanded && isPressed.value && isTopCard) 1000f else targetZIndex,
        animationSpec = ZINDEX_TWEEN
    )
}
```

