> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 重构 `SwipeableImageStack.kt`，消除堆叠态/展开态两套独立渲染循环，合并为一套；严格对齐原型 `expand-collapse-stack.html`；修复 3 个 Bug：① 收起按钮与时间线重叠 ② 展开后图片空白/窄幅重叠 ③ 横向等距排列不一致；**严格保证堆叠图/角标/展开按钮位置绝对不变**。

**Architecture:** 
- 根节点 Stage Box（size 永远=堆叠态需求，永不挂 horizontalScroll）

- 卡片实例永不重建，过渡动画最流畅；对外 API 0 改动，调用方无需改代码
