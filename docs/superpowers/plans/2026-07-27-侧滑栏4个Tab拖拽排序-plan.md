> ⚠️ **本计划为规范文档**：任务清单保留为实施规范参考。实际执行情况请见文末"实施总结"章节。

**Goal:** 为侧滑栏 4 个 Tab（TODO / DATE / INSPIRATION / PROFILE）添加长按拖拽排序功能，立即持久化，重启后保留顺序。

**Architecture:** 4 个 Tab 各自独立实现 Reorderable 库接入，共享同一套拖拽模式（LazyColumn + longPressDraggableHandle + 标准 Reorderable 视觉）。持久化方式因数据源不同而异：DB Migration（GROUP）/ ESP（STATUS）/ 已有 sortOrder（DATE）/ 新建表（INSPIRATION / PROFILE）。

**Tech Stack:** Jetpack Compose 1.9.2 + Material 3 + Reorderable 库 + Room + Hilt + DataStore (ESP)

**Spec:** [2026-07-27-侧滑栏4个Tab拖拽排序-design.md](../specs/2026-07-27-侧滑栏4个Tab拖拽排序-design.md)

**测试策略:** 无自动化测试，每 Phase 末尾有手动验收清单 + 编译验证询问 + 提交询问
