# Compose 编辑器弃用备份

> 备份日期：2026-09-17
> 原因：灵感编辑页正文已由 BlockNote（WebView）编辑器接管，原 Compose 版富文本编辑器彻底下线。

## 背景

灵感编辑页正文编辑器经历了如下演进：

1. **Compose 自研块编辑器**（`BodyBlocksEditor`，基于 `compose-rich-editor` 的 `RichTextState` 逐块编辑）
2. **BlockNote（WebView）** —— 解决跨块文字选择、选区手柄等 Compose 方案难以修复的问题

BlockNote 迁移按 `docs/BlockNote迁移实施计划.md` 推进，编辑页正文由编译期开关
`USE_BLOCKNOTE_EDITOR` 控制切换。开关默认 `true` 后，Compose 版编辑器代码以
「开关 + 全分支」形式保留，本次将其彻底删除。

## 本目录内容

| 文件 | 原路径 | 说明 |
|---|---|---|
| `components/BodyBlocksEditor.kt` | `app/src/main/java/com/corgimemo/app/ui/screens/inspiration/components/BodyBlocksEditor.kt` | Compose 版块级富文本编辑器（5212 行），编辑页正文的核心实现 |
| `components/RichTextFormatToolbar.kt` | `app/src/main/java/com/corgimemo/app/ui/screens/inspiration/components/RichTextFormatToolbar.kt` | Compose 版格式工具栏（粗体/斜体/字号/颜色/缩进等），已被 BlockNote JS 工具栏替代 |
| `CoilRichTextImageLoader.kt` | `app/src/main/java/com/corgimemo/app/ui/components/CoilRichTextImageLoader.kt` | `compose-rich-editor` 库的 Coil 图片加载器实现，仅供 `BodyBlocksEditor` 使用 |

同目录另有历史拆分文本 `BodyBlocksEditor.kt.splitbak` / `.splitbak2`（未一并备份，
如需查阅可从 git 历史获取）。

## 保留事项（未删除）

以下内容**仍然在使用**，不属本次删除范围：

- **富文本只读渲染**：`InspirationViewCard.kt` 中的 `RichText` 只读渲染与
  `MarkdownParser` / `MarkdownInlineRenderer` / `HighlightUtil` —— 灵感详情页正文
  与列表摘要仍依赖它们，删除会导致详情页正文白屏。
- **`compose-rich-editor` 源码子模块目录**：`compose-rich-editor/` 为独立 git
  submodule，物理目录保留；仅从 `settings.gradle.kts` 与 `app/build.gradle.kts`
  中解除构建依赖。

## 后续若需回退

本目录文件可作为参考实现查阅。若需恢复编辑页 Compose 版，需同时恢复：

1. `app/build.gradle.kts` 中 `implementation(project(":richeditor-compose"))`
2. `settings.gradle.kts` 中 `include(":richeditor-compose")` 与 `projectDir` 映射
3. `InspirationEditScreen.kt` 中的开关分支与 `BodyBlocksEditor` 调用

因此本目录仅为**文本查阅副本**，不能直接放回源码目录即恢复功能。
