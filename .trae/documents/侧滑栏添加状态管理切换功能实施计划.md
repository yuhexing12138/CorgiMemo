# 侧滑栏添加"状态管理"切换功能 实施计划

> **创建日期**：2026-07-27
> **状态**：待用户确认后实施
> **关联规范**：[.trae/rules/巨石组件拆分规范.md](../../rules/巨石组件拆分规范.md)、[.trae/rules/项目级AGENTS.md](../../rules/项目级AGENTS.md)

## 一、目标

在待办页侧滑栏的"分组管理"标题**右侧**添加"状态管理"标题，二者**互斥切换**（类似 Tab 风格）。状态管理模式下显示 5 个状态过滤项：**置顶 / 待完成 / 已完成 / 已过期 / 重复提醒**，与现有"分组管理"分类过滤是**组合关系**（AND），实现精细化筛选。

## 二、用户确认的设计决策

| 决策点 | 选择 | 说明 |
|--------|------|------|
| 交互模式 | 互斥切换（Tab 风格） | 激活区域有"加粗 + 主题色 + 橙色横线"高亮 |
| 过滤行为 | 组合过滤 | 状态过滤 + 分类过滤可同时生效（AND） |
| 视觉样式 | Tab 风格 | 激活标题加粗 + Primary 色 + 橙色横线，与现有"分组管理"一致 |
| 底部按钮 | 添加分组 | 两种模式共用"添加分组"按钮（分组管理才有意义） |

## 三、当前架构现状（关键信息）

| 模块 | 现状 |
|------|------|
| **AppDrawer 拆分** | 已按规范拆为 `model/ sections/ dialogs` 三层，薄壳在 `AppDrawer.kt` |
| **TODO Tab 渲染** | `AppDrawerContentImpl` → `CategoryGroupSection`（标题"分组管理"） |
| **复用组件** | `CategoryItem`（internal，4 个 section 共用，可直接复用） |
| **HomeViewModel 现有 StateFlow** | `pinnedCount` / `pendingCount` / `completedCount` / `selectedCategoryId` / `filteredTodos` |
| **HomeViewModel 缺失** | **无** `overdueCount` / `repeatReminderCount` / `statusFilter` / 状态过滤方法 |
| **TodoItem 字段** | `isPinned: Boolean`、`status: Int`、`dueDate: Long?`、`repeatType: Int`（0=不重复, 1-6=各种重复） |
| **isOverdue 工具** | `MoodManager.isOverdue(dueDate, currentTime)` 返回 `Boolean`（无副作用、可直接调用） |

package com.corgimemo.app.viewmodel

/**
 * 状态过滤器（v2026-07-27 新增）
 *
 * 侧滑栏"状态管理"分区专用。用于在 HomeViewModel.filteredTodos 中应用状态维度过滤。
 * 与"分组管理"中的 _selectedCategoryId 是**组合关系**（AND），可同时生效。
 */
enum class StatusFilter {
    ALL,             // 全部（默认）
    PINNED,          // 置顶（isPinned=true）
    PENDING,         // 待完成（status=0 且非置顶）
    COMPLETED,       // 已完成（status=1）
    OVERDUE,         // 已过期（status=0 且 dueDate < now）
    REPEAT_REMINDER  // 重复提醒（repeatType != 0）
}

```kotlin
// 新增 _statusFilter 到 combine 列表
kotlinx.coroutines.flow.combine(
    baseFlow, _searchQuery, _selectedCategoryId, _showCompleted, _hideCompletedItems, _statusFilter
) { baseList, query, categoryId, showCompleted, hideCompletedItems, statusFilter ->
    var result = if (hideCompletedItems || !showCompleted) {
        baseList.filter { it.status == 0 }
    } else {
        baseList
    }
    
    // ★ 新增：状态过滤（与分类过滤 AND 组合）
    if (statusFilter != StatusFilter.ALL) {
        result = when (statusFilter) {
            StatusFilter.PINNED -> result.filter { it.isPinned }
            StatusFilter.PENDING -> result.filter { !it.isPinned && it.status == 0 }
            StatusFilter.COMPLETED -> result.filter { it.status == 1 }
            StatusFilter.OVERDUE -> result.filter { todo ->
                todo.status == 0 && MoodManager.isOverdue(todo.dueDate)
            }
            StatusFilter.REPEAT_REMINDER -> result.filter { it.repeatType != 0 }
            StatusFilter.ALL -> result  // unreachable
        }
    }
    
    // 分类过滤保持不变
    if (categoryId != null && categoryId > 0) { ... }
    else if (categoryId != null && categoryId == 0L) { ... }
    
    if (query.isNotBlank()) { ... }
    
    result
}
```

// app/src/main/java/com/corgimemo/app/ui/components/appdrawer/sections/DrawerSectionTab.kt
package com.corgimemo.app.ui.components.appdrawer.sections

@Composable
internal fun DrawerSectionTab(
    currentSection: DrawerSection,
    onSectionChange: (DrawerSection) -> Unit,
    modifier: Modifier = Modifier
) {
    Row(
        modifier = modifier
            .fillMaxWidth()
            .padding(horizontal = 20.dp, vertical = 8.dp)
    ) {
        DrawerSectionLabel(
            text = "分组管理",
            isActive = currentSection == DrawerSection.GROUP,
            onClick = { onSectionChange(DrawerSection.GROUP) }
        )
        Spacer(Modifier.width(24.dp))
        DrawerSectionLabel(
            text = "状态管理",
            isActive = currentSection == DrawerSection.STATUS,
            onClick = { onSectionChange(DrawerSection.STATUS) }
        )
    }
}

@Composable
private fun DrawerSectionLabel(
    text: String,
    isActive: Boolean,
    onClick: () -> Unit
) {
    Column(
        horizontalAlignment = Alignment.CenterHorizontally,
        modifier = Modifier
            .clip(RoundedCornerShape(8.dp))
            .clickable(onClick = onClick)
            .padding(horizontal = 4.dp, vertical = 4.dp)
    ) {
        Text(
            text = text,
            fontSize = 16.sp,
            fontWeight = if (isActive) FontWeight.Bold else FontWeight.Normal,
            color = if (isActive) UiColors.Primary else Color(0xFF1C1B1F)
        )
        Spacer(Modifier.height(6.dp))
        Box(
            modifier = Modifier
                .height(3.dp)
                .fillMaxWidth()
                .background(if (isActive) UiColors.Primary else Color.Transparent)
        )
    }
}

| 新增 5 个 StateFlow 影响性能 | 低 | 使用 `_todos.map` 复用同一个源数据流，5 个 flow 都是 WhileSubscribed(5000) |
| AppDrawer 24→33 参数膨胀 | 低 | 薄壳层负责透传，调用方 MainScreen 显式传入 |
| StatusFilter.PENDING 与现有 PENDING 区段名冲突 | 低 | enum 是 `StatusFilter.PENDING`，无冲突 |
| 状态过滤 "全部状态" 项选中时 count 应等于"全部待办" | 中 | 用 `totalTodoCount` 而非 `pinnedCount+pendingCount+...`（避免 30 天已完成的差异） |

## 八、后续可优化点

1. **状态过滤项图标**：当前用 emoji（📌/⏳/✅/⏰/🔁），可后续改为 Material Icons（filled）统一视觉
2. **持久化 statusFilter**：当前状态不持久化，App 重启后回到 ALL。可在 DataStore 加 `key_status_filter`
3. **statusFilter 选中态时 topBar 显示**：选中状态过滤时，topBar 显示"状态: 置顶"等小标签，让用户清楚当前过滤
4. **过期数计算性能**：当前是 `count { ... }` 在每次 todos 更新时计算，数据量大时可改 DAO 聚合查询
5. **批量操作时禁用状态切换**：避免批量选择中切换状态过滤导致选择丢失
6. **AppDrawer 33 参数进一步优化**：后续可考虑把 5 个状态计数合并为 `data class StatusCounts(val pinned: Int, ...)`
