单选选择器型底部弹窗

用于从一组互斥选项中选择一个，如优先级选择、排序方式选择。当前选中项有暖橙色高亮标记，点击新选项自动切换。

  • 选中项背景使用 #FFF0E5 暖橙浅色背景
  • 选中项左侧有 3px 宽暖橙竖条标识
  • 选中项右侧显示 Lucide check 图标（#FF9A5C）
  • 未选中项默认白底，hover 时背景 #F8F6F3
  • 每行包含 Lucide 图标（20px）+ 文字（16px Medium），左对齐排列
  • 选项行 padding：上下 14px / 左右 24px，行高约 52dp

项目弹窗完整清单

以下是 CorgiMemo 项目中所有属于「单选选择器型」的弹窗实例：

弹窗文件 当前实现 如何调出 状态
PriorityPickerSheet.kt ModalBottomSheet 待办列表页 → 右上角"⋮"三点 → 批量选择 → 选中待办 → 底部操作栏"更多选项"（⋮）→ "优先级"按钮，弹出无/低/中/高四选 1（注意：待办编辑页内联优先级仍使用 AlertDialog，非此组件） ✅ 符合规范
DateTypePickerBottomSheet.kt ModalBottomSheet 特殊日期模块 → 新建或编辑日期卡片 → 点击"类型"字段，在生日/纪念日/倒计时等类型中单选 ✅ 符合规范
ThemePickerBottomSheet.kt ModalBottomSheet 特殊日期模块 → 编辑日期卡片 → 点击"主题"字段，选择卡片配色主题 ✅ 符合规范
OutfitQuickSwitchSheet.kt ModalBottomSheet 首页（HomeScreen）→ 长按底部导航栏上方的柯基角色 → 弹出已解锁装扮列表，点击即可快速切换（另 CorgiDetailScreen 中虽有组件渲染但无 UI 触发入口，该路径不可达） ✅ 符合规范
ColorPickerBottomSheet.kt ModalBottomSheet 待办编辑页或灵感编辑页 → 点击顶部导航栏右侧的调色板图标（🎨），弹出 12 种预设背景色供单选 ✅ 符合规范
ReminderPickerBottomSheet.kt 自定义遮罩弹窗 待办编辑页 → 点击分组容器内的"提醒"按钮 → 弹出全屏半透明遮罩 + 居中定位的提醒时间设置面板（非底部弹窗，由 Box + 自定义 Layout 按 4:1 比例固定定位），包含日期选择、时间滚轮、重复提醒、截止日期 ⚠️ 非底部弹窗，不在本规范范围内
